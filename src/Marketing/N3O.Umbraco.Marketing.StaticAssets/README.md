# N3O.Umbraco.Marketing.StaticAssets

Brings in the Umbraco Engage static assets, and the Engage assets for Umbraco Forms, alongside
`N3O.Umbraco.Marketing`.

It contains no code of its own. Install it in the web project, which is where Engage's back office
and client-side assets have to land; the code that uses them is in the other package.
