# N3O.Umbraco.TaxRelief.UnitedKingdom

Implements Gift Aid as a tax relief scheme. A gift attracts a quarter of its value, and only
individuals resident in the United Kingdom are eligible, so an organisation or a supporter resident
elsewhere is not offered it.

The declaration wording an editor must show alongside the claim is held in Umbraco settings content
rather than in code, because it is the charity's own wording and has to be changeable without a
deployment.
