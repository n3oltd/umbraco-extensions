# N3O.Umbraco.Forms

Brings in Umbraco Forms alongside `N3O.Umbraco.Extensions`, so a site takes one dependency and gets
both at versions known to work together.

It contains no code of its own. This is the assembly-reference half of the pair; the back office and
client-side assets are in `N3O.Umbraco.Forms.StaticAssets`.
