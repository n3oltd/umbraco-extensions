# N3O.Umbraco.Uploader.StaticAssets

Ships the back office editor for the uploader property, with the progress indicator and drop target,
as an App_Plugins bundle with a targets file that copies it into the consuming site.

It contains no C#. `N3O.Umbraco.Uploader` provides the server side and enforces the limits; without
this package the property has no editor.
